# Garvit Lodha — Personal Universe

A Gen-Z / anime-inspired academic-personal website for GitHub Pages.

## Publish on GitHub

1. Create a new repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload **everything inside this folder** (not the outer folder itself).
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Wait for GitHub Pages to publish the site.

## Update your content

Open `index.html` and edit the text in:
- `CURRENT ARC`
- `RESEARCH UNIVERSE`
- `CHARACTER PROFILE`
- `ACADEMIC TIMELINE`
- `QUOTE ARCHIVE`

Images are in `assets/`.
